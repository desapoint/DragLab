# S06c core pilot

`TypedFluidRefillPilot` adds an owner-thread manual oil/coolant quote, command, and publication path over the S04 planner and S06b selected-owner coordinator. `TypedFluidRefillQuote` contains only immutable request, binding, owner-receipt, read-set, and display facts. Its typed quote cache is bounded to eight dependency keys and expires quotes at their request deadline. A matching cache key is not sufficient by itself: before returning a hit, the pilot compares the exact scoped live values (cash, all 14 fluid bits, capacity-bearing installed parts, car/engine/job/rebuild identity, unsettled-run gate, receipt window, saved economy clock and fluid prices) directly. This small validation does not call planner Capture, full build Resolve, JSON, or profile cloning. A stale cached entry falls through to the regular authoritative Capture/Plan path and receives newly issued immutable terms.

Confirmation acquires the selected-owner lease before fresh S04 capture. The pilot compares the shown request and exact scoped read set, replans at the accepted tick, rejects changed price/capacity/cash terms, and prepares the target reference and bounded (maximum 256) economy receipt list before dispatch. The worker receives the immutable command only.

Polling does not wait. Publication requires the direct writer's same-transaction observed storage commit to equal the operation's committed token, the same owner/profile/path/slot/epoch and global versions, and an equal fresh scoped read set including the 14 fluid values. It assigns only cash, revision, storage commit, economy clock, target oil/coolant quantities, and the staged receipt list. Historical replay restores the actual stored receipt when retained; if the receipt has been evicted, the existing bounded list is retained without inventing a replacement.

Known durable results that cannot be published remain coordinator-owned and require `TryRecover`. The controlled recovery seam permits only the exact held lease with a completed committed result to use the existing validated selected-owner load path. Selection, reset, ordinary save, and unrelated load guards remain closed. Recovery keeps the lease and controlled token through receipt validation, then acknowledges the operation and preserves the validated current proof before clearing the lease. The caller must replace its profile reference in the same main-thread call path. This explicit fallback may incur the existing legacy/load cost; ordinary quote, confirmation, polling, and publication do not use it.

The durable outcome now carries optional `ObservedStorageCommit` to preserve compatibility with generic S06a callers. Fresh commit reports the committed token; replay/reconciliation reads the current token inside the same SQLite transaction. Active pilot publication requires this observation. The owner helper prepares the next proof, invokes only the staged field-assignment callback while the lease remains held, verifies the resulting versions, acknowledges, then swaps proof and clears the lease with field assignments.
