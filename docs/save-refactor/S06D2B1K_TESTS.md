`CartPreviewCharacterizationChecks.RunOrderedInventoryMove` (in `OrderedInventoryMoveProjectionChecks.cs`) is the Editor-only, finite characterization entry point for the ordered raw-domain sequence projection. It compares the candidate with the frozen `LegacyOrderedInventoryMoveReference` and the current `SharedInventory.Move` row loop on isolated literal copies. Failure checks require no output graph and no source prefix writes. Output checks compare actual typed part copies, engine and car snapshot fields, definitions maps, descendants, and concrete loose-unit element subtype/history.

The 100-distinct workload records five warmups and fifteen bounded Editor timing samples. It reports median and p95 only; allocations are marked unavailable and this is not native frame/device acceptance.
