## Validation boundary

The new sale-price reference copies the current `ValidateForQuote` wrapper and both `ValidateCore` passes, including the dealer-discriminator tolerance branch. It also copies the current SharedInventory, PartsMarket, CartReservations, SavedSetups, and `VehicleListings.ValidateCore` bodies, redirecting their catalog lookups to the frozen catalog adapter. The VehicleListings wrapper/cache is not called by this copy. It does not use `OwnershipValidationLegacyReference` as expected output. The remaining direct validators (`VehicleInspection`, `PaidEconomy`, `CareerProgression`, `GarageBusiness`, `OwnershipValidationLookup`, `MassDynamics`, `EngineRebuilds`, and schema/member predicates) and the copied validator's direct model-validation leaves have exact method hashes listed in the provenance report. These bodies and files must remain pinned until high approves the ledger.

## Oracle boundary

All JSON copies and normalizing writes belong only to `LegacyCartQueryReference.Total`'s lazy Move validation copy and `PreviewProfile`'s disposable legacy output copy. They are permitted to preserve and diagnose historical behavior; they are not candidate behavior and never escape as a proposed live profile. Query liveness compares independent authored fixture pairs; it does not use `LegacyCartPreviewOracle` as an oracle because that older file calls mutable production query helpers. No caller, checkout, persistence, UI, cache, or candidate API is activated here.
