## Implementation scope

This checkpoint adds only `CartRowsSnapshot.cs` and `PartProductValue.cs` with Unity metadata. It leaves all existing Domain helpers and live routes untouched. These values are dormant, synchronous captures for the L1A diagnostic; they do not replace JSON-backed `CartReservations.Lines`/`SameCart`, `MarketCatalogLayout.Key`, `PartsMarket.ProductKey`, or any stock/caller behavior.

`CartRowsSnapshot.Capture` copies the source enumerable once in order, retaining repeated rows and a null-row marker. `CartRowValue` stores each serialized line field as readonly scalars/immutable strings and private copied position data. `GetRow` returns the immutable owned value; `PositionAt` reads one copied item and `CopyPositions` returns a defensive array. `RawEquals` distinguishes null row/default row, all null/empty pairs, null/empty position lists and elements, values, and order. `CartSignatureEquals` builds no domain rows: it compares the effective frozen signature rules separately, normalizing null rows to exact `PartCartLine` field-initializer defaults, five L0 nullable strings to empty, null positions lists to empty, and null position items to empty. Null source throws `ArgumentNullException("source")` before enumeration, matching LINQ `Select`; no catch or filter changes enumeration failures.

Cart row enum fields compare directly with their enum operators; no boxed `Enum.Equals` calls are used. Effective cart string/position comparisons use the same observed streaming UTF-16 rule as product keys; raw cart equality remains exact.

`PartProductValue.Capture` copies a `PartDefinition`'s primitive/string value graph without invoking `Copy`, reflection, JSON, or caching. It retains the source ID for raw comparison but excludes it from product equivalence. All seven serialized string fields, all top-level scalar/enum fields, both AWD reference-presence flags and every `AwdHardwareSpec`/nested `AwdSpec` scalar are stored as owned values. Floats are retained as raw IEEE bits for `RawEquals`. Missing AWD object/calibration slots store the corresponding explicit default scalar values alongside separate null-shape flags; only product equivalence ignores those flags. The static `FieldPaths` metadata is a defensive array copy, includes `id` as raw-only and the `awdHardware`/`calibration` reference paths, and never uses runtime reflection.

Closed enum fields are converted with explicit `int` casts into the scalar buffer, avoiding generic conversion and boxing allocations.

The product API is fail-closed by shape/implementation support: `TryProductEquivalent` returns supported equality or supported inequality for the closed mapped value graph; a null other is supported/not-equal. It does not shortcut unsupported self-comparison. `TryGetProductHashCode` computes a deterministic field-order hash over the effective graph. Product strings map null to empty and use an allocation-free streaming match for Unity's observed malformed UTF-16 behavior: a high surrogate consumes the next code unit, emitting the valid pair when that unit is low or one U+FFFD otherwise; a standalone low surrogate emits U+FFFD. Raw equality retains original code units. Floats map signed zero to zero and all NaN payloads to one canonical NaN value, and absent AWD references map to their explicit default scalar slots. Every equal supported pair therefore has the same hash; exact comparison is still required after a hash match. This intentionally is not a key string or identity. The seven string mappings, all nested default behavior and all float canonicalization remain subject to the required frozen-oracle vectors; source availability alone is not proof.
