# S02b independent review

**Verdict: PASS for the bounded installed-binding lookup checkpoint.** This approves only the operation-local lookup and the `MechanicsOwnership.Definitions`, `MechanicsOwnership.Resolve`, and non-cart `InspectionBuild.Capture` integrations. It does not approve later command migrations or completion of the save-state refactor.

`InstalledPartLookup` captures binding order and slot strings, resolves requested IDs through the scoped S02a index, and returns borrowed actual `PartInstance` references only inside a synchronous `using` scope. Its copied definition map is independent. Missing and blank IDs remain absent; the over-request fallback, duplicate-category behavior, disposal, fresh capture after same-count replacement, typed component copies, and read-only source preservation have regression coverage. The integration keeps fitment and warning reads synchronous and disposes the lookup before returning. No global cache, live-worker traversal, whole-profile clone, or JSON manipulation was added.

The public differential checks compare against ordered `List.Find` scans. Three authored representatives cover definitions, resolution, inspection, diagnostics, component order and typed identity/condition/resource fields. The focused final-source rerun varies fitting tire definition IDs between front and rear while preserving the physical part and individual tire/member identities; full serialized spec equality covers the corner tire definitions. The earlier full run passed 250 parity/scaling checks plus 72 isolated storage checks, exit 0. The final-source focused parity run passed 220 overlapping checks, exit 0. The first compile attempt failed with CS0136 and CS0104; those were corrected before the accepted runs, and the failed log is retained.

The 36-case helper comparison covers three authored vehicles, four part-list sizes through 30,000, and first/last/shuffled placements with five warmed samples. At 30,000 parts, the new capture median was 0.071–0.094 ms for first placement, about 1.70–1.78 ms for last placement, and about 1.74–1.83 ms for shuffled placement; the legacy scan medians were 0.098–0.134 ms, 15.3–18.5 ms, and 6.2–9.6 ms respectively. The independently validated CSV reports no median regressions. These are bounded Editor measurements, not frame-tail, allocation, full-command, packaged-player, or phone measurements; sample maxima are not percentiles.

The source-topology precondition remains material: requested-ID capture can stop before an unrelated tail, so this helper does not validate the whole ownership graph or promise parity on corrupt duplicate-ID state. Borrowed handles are mutable references, not immutable snapshots; callers must keep them within the synchronous lifetime and away from mutation, callbacks, publication, and worker handoff. The existing detached-engine and cart-preview paths remain separate.

No persistence authority or durable command changed in S02b. Existing whole-profile JSON cloning and JSON-based runtime manipulation remain unfinished hard-gate work. Passing this checkpoint does not waive the requirement to remove those dependencies from every migrated production path before final completion.
