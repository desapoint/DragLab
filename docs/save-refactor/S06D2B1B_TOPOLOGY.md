# S06d2b1b topology characterization probes

**Status:** Editor-only characterization code added; not executed in this handoff. These probes expand the existing full [matrix](S06D2B_CHARACTERIZATION_MATRIX.md) and [coverage review](S06D2B1_COVERAGE_REVIEW.md); they do not close S06d2b step 1. Known legacy JSON mutation remains an expected red finding. No typed candidate, production switch, or healing fix is part of this increment.

The added `CartPreviewCharacterizationTopology.RunTopologyMatrix(Trace,string subset=null)` uses the existing partial checker, frozen `LegacyCartPreviewOracle`, literal profile copier, exact `CompareTotal` / `ComparePreview` comparison, and actual normalized fixture factories. A null subset runs all groups. Supported diagnostic subsets are `members-corners` (member and corner topology), `owners-parts` (engine and part ownership), and `blocks-locks` (block preparation and reservations). Any non-null value outside those three names throws `ArgumentException`. Start/end trace records include the selected subset so partial runs cannot be mistaken for the complete topology matrix. Each independent group starts with a fresh valid fixture. Fixture discovery failures are written as `OPEN` with the specific missing authored shape; the test does not invent IDs, definitions, engine specs, member roles, faults, or corner records.

The valid source fixture is untouched. |
| Garage/rebuild locks | Call `GarageBusiness.Assign` for the actual `photo-session` offer or `EngineRebuilds.Start` on separate valid fixtures; move an actual fitted part | Compare exact first lock error from `PartCart.Total`. A failure to create the real reservation is recorded `OPEN`, not treated as passing the lock check. |

All paired calls use distinct literal copies as enforced by the shared comparator. The additional direct preview and `BlockPreparation.Build` inspections also run on literal isolated inputs and explicitly compare before/after source, shared-catalog, row and Unity random snapshots. The block plan is built on an isolated valid source; follow-on Total/preview comparisons receive a fresh equivalent literal profile so a Build-side mutation cannot turn into `PAIR_SKIP` or change their baseline. Untouched corner facts are captured as immutable runtime-type/canonical strings before Total, preview, or direct-preview calls. Target engine fluids/tune, non-target starter fluids/tune, and the selected-car graph are likewise captured before the owner-return calls; cross-owner selected-car facts are captured before its comparisons. The diagnostics then emit those captured before values beside exact typed after values and first-difference character/field context before strict equality assertions. The Aster member-count probe uses the actual resolved installed build spec rather than the model's base spec. Any new physical IDs are compared with the existing comparator's current output-path mapping; the matrix's stronger row/action/quantity/member-key bijection remains an open coverage gap.

## Limits retained

- The six and eight cylinder counts are optional strata. The required assertion is for the actual available multi-cylinder authored topology, not an invented six/eight cylinder setup.
- No UI callback, selected-row dialog, native input, viewport, or frame timing case runs here. Those remain separate native evidence gates.
- The current code writes exact results, but no execution was performed by this author. Parent owns the Editor wrapper/run, source hash and trace version updates, comparison of failures, and final integration.
- The primary checker now invokes `RunTopologyMatrix` in both strict and collect-all paths. That wiring makes the cases part of the next run, but no execution or reviewed Editor result was produced in this handoff.

Coordinator refinement before execution: a mutation of the disposable BlockBuild input remains a strict failing assertion with a captured difference. A ready returned plan may still be compared on a fresh exact source when the original caller graph, shared catalog, RNG and supplied rows stayed unchanged. This collects the independent downstream baseline without accepting the mutation or reusing its damaged input.
