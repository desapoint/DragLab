## Entry point and oracle

`CartPreviewCharacterizationChecks.RunCartApplyReference(Action<bool,string>, string)` is implemented in `Game/Assets/DragLab/Scripts/Runtime/CartApplyReferenceChecks.cs` and is compiled only under `UNITY_EDITOR`. It compares unchanged `PartCart.Apply` to the independent `LegacyCartApplyReference.Apply` in `LegacyCartApplyReference.cs`. Both return `void`; the report records the observed graph and first exception/partial prefix rather than assuming a success value.

Each case starts from an actual normalized authored fixture. The profile is isolated with the existing literal test-only clone, then each disposable execution receives a separate `MechanicsTransactions.Catalog()` instance. The checker compares the authored definitions/specs and private lookup-index shape before the calls, verifies the catalog instances do not alias, and compares catalog/index effects afterward. Dedicated layouts cover warm indexes, independently cold indexes, an actual copied definition alias linked into its market row, and a null public catalog row that makes the next real lookup rebuild fail at its natural point. No cache write from one execution prepares the other.
