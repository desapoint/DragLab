# S06d2a typed Parts facts test matrix

Verifier: `NativePartsReadSetChecks.Run(Action<bool,string>, string fixtureDirectory)`. This is a dormant managed support step only; it does not connect to `NativeParts.RefreshParts` or claim a native responsiveness pass. Parent owns the Editor runner and Unity/Git execution.

| Gate | Oracle and mutation cases |
| --- | --- |
| Capture/advance/finish | Capture with 1, 5, and 20 cars bought through `VehicleCollection.Buy`, asserting real unique car, engine, part and typed-member rows grow with the roster; also cover the small one-vehicle authored catalog and full authored catalog. Exercise Shop, Inventory and Installed page scopes. Null, empty, wrong-case and unknown page names must throw `ArgumentException` after the main-thread guard rather than certify an empty scope. Repeated `Advance(itemCap, softMilliseconds)` must stay within the item cap and terminate under a finite guard. A matching `TryFinish(currentInputs, ...)` yields one complete read set; early/stale finish yields no result. Mutating source shape during a slice must expose a terminal failure, avoid spin/publication, and allow a fresh capture after cleanup. Report pure capture time, largest slice, final compare, source counts and separately labeled wall time including check-callback overhead; timings are descriptive with no pass threshold. |
| Owner and request identity | Capture owner slot/path/epoch on main. Independently change slot, path case/value, epoch, profile reference, `revision`, `storageCommit`, catalog reference, selected-car reference/IDs, page and planned mode; each changed model input must reject. Use synthetic contexts for comparer semantics and switch/restore the actual selected slot to prove the old input wrapper is rejected against current ownership. Path casing follows platform semantics (case-insensitive on Windows). |
| Typed copy and field guard | Compare `ComparedSerializedFields()` and `AuthoredComparedFields()` with Unity serialized fields on each listed runtime type, including inherited/`SerializeReference` members and concrete engine-element subtypes. Mutate comparator fields independently and assert exact bitwise mismatch, including positive-zero/negative-zero distinction for float and double. Include nested AWD, clutch, installed-build, slot-binding, loose-member and market-row schema. |
| Car/condition facts | Exercise `Tune` and AWD calibration, fuel, all 14 `FluidState` doubles, engine assembly/garage/rebuild lock fields and ordered replacement targets, installed binding order/IDs, `PartInstance.Copy` identity/storage/location/owner/slot, component history/fault/resource values, ordered element IDs and runtime member types, tire-only condition fields and spare corner-fitment definition IDs, clutch null/present state/version/oil litres/condition, and null/missing arrays or objects. Replace/remove an object while reusing its ID and reorder installed/member lists. No normalization or state write is allowed. |
| Commerce/page scope | Change market seed/generation, row identity/order/aliases/units/delivery percent, active reservation clock/owner/generation/supply order, dealer identity/definition/condition and paid price, cash/reputation, supplied nullable price facts and their order. Change authored price, definition ID, and same-ID/same-content object identity at the same count/revision; the retained token must reject without canonical JSON encoding, then accept the restored or legitimately rebuilt catalog. Test Shop, Inventory and Installed scopes; for Shop, changing wear/tune on an unrelated car at the same profile revision must remain current, while changing a selected/displayed asset must invalidate. |
| Cart, units and nonempty-cart boundary | Compare every ordered cart-line field (action, IDs, quantity, install/prepared owner, role, destination and ordered positions), plus UnitPreferences version/speed/pressure/torque. Preserve null positions distinctly from an empty list for both caller cart lines and active reservation lines; unchanged null matches, null-to-empty rejects, and cleanup restores the original state. Empty cart can be a base read-set; nonempty lines must set `RequiresTypedPreview` and must not certify a planned preview or call `PartCart.PreviewProfile`. |
| Side effects and thread ownership | A test-only bit-preserving typed graph stamp checks the serialized profile/catalog definitions plus supplied settings and prices before and after each Shop, Inventory and Installed capture, advance, finish and match; explicitly compare catalog/list identity and authoring revision, selected owner slot/path/epoch, and canonical-encoding count too. Final comparison must safely reject null parts, loose-unit or selected-car collections and a cleared selection without throwing; every fixture mutation is restored in `finally`. Owner-thread guards are enforced before live profile access; test cross-thread invocation only if it can be bounded without blocking a Unity owner callback. The shipping read-set path uses no reflection, JSON fingerprint, full-profile clone, or disk write; reflection is confined to Editor/Development verifier guards. |

For each mutation, create a fresh current-input wrapper from the mutated fixture and compare against the original completed read set; also check unchanged inputs match. Validate that `Advance` copies caller-owned cart lines, unit preferences, owner scalars and price facts at session start. Keep private captured facts inaccessible to mutation by the caller. Report max indivisible capture and final compare separately from the soft slice budget; an over-budget tail remains an open S06 blocker, never averaged or weakened.
