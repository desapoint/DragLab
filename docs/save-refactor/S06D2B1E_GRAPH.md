## Audit and interpretation limits

`CompareTotal` and `ComparePreview` compare production legacy behavior with the frozen legacy oracle; they are not typed-candidate checks. `GraphAuditedPreview` runs the direct preview on an isolated literal profile and separately snapshots profile/catalog values, exact typed field paths, reference identity paths, ordered row values/references, Unity RNG, and identity emission. Output field/reference changes go to bounded trace summaries and local sidecars. Known serialization-triggered null/dealer changes remain strict failures; the graph tests do not warm or normalize them away. For the stored-engine roundtrip only, the known domain transition from attached part to Garage and back is checked independently; the end-to-end part comparison has one explicit expected storage-field transition, while egress condition differences and all other returned fields remain strict.

Before each block Reuse build, the fixture computes the selected replacement block's actual resolved spec and required categories from the authored recipe. It moves only real fitted parts that match those requirements to Garage through `SharedInventory.Move`, then verifies the same physical IDs appear as the builder's Move companions. This preserves IDs and makes the companion rows target-scoped. The multi-target case proceeds only when actual market stock, both physical block instances, two ready real plans, distinguishable missing-category errors, and collision-free combined rows are available. Plans with target-ambiguous NewSet companions remain `OPEN`, because those rows resolve through the selected-car argument. The ordered pack/unit cart is rejected by `Total` before preview in both orders. Its direct `PreviewProfile`/Apply calls characterize the legacy method when invoked outside a successful quote; those outputs do not imply a valid cart or approval to bypass quote validation. The case also requires an actual alternate compatible authored pack and real matching role/position. No absent asset or topology is synthesized to force a pass.

No run result, compile result, typed policy approval, runtime switch, performance result, or overall S06 completion is claimed by this source draft. The current source-level behavior is observational evidence only. The future scoped planner must preserve valid optional nulls, avoid preview-time `Ensure`/normalization, use exact authoritative errors for genuinely invalid dependencies, and preserve all unrelated owners and physical identities; these tests do not implement or approve that planner.
