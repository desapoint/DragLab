## Findings resolved before this review

- Existing tire source records are validated before COW edit or `Ensure`; selected blank source member IDs are rejected at the raw allocation point, while unselected blank members remain intact.
- Candidate overlays and COW copies are keyed by source object identity, source rows precede additions, and nested K/I/J lookups use the shared scoped catalogue capability.
- First-touch order, source ordinals, insertion ordinals, and deletion-only tombstones are explicitly represented. Candidate-only append/remove rows are omitted from final row arrays while identity/effect history remains.
- The C1 checker no longer treats final graph differences alone as its expected write set. It unions per-step frozen changes so touch-then-restore writes remain expected, adds documented idempotent targets, and rejects extra unchanged records.
- Sequential frozen replay independently checks each acquisition quote (`Cost`, `Fee`, `LocalUnits`, `ExpressUnits`) and compares replay final profile/catalogue/market/cash state with the monolithic frozen result after mapping generated identity events.
