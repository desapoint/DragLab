# S06d2b1j — shared whole-engine move core

This bounded slice extracts the existing whole-engine Move, Detach, Attach and fit behavior into shared operations. `SharedInventory.Move` and the public `AssemblyOperations.Detach/Attach/Fits` routes now call `InstalledEngineTransition`; the dormant `WholeEngineMoveProjection.Evaluate` uses the same transition with invocation-local copy-on-read state. The existing unit and whole-part branches remain separate. No UI, cart, persistence, worker, JSON, full-profile clone or save path was added.

The common Move preamble retains unsettled-run, Storage existence, and unit-before-engine-before-part lookup order. The engine core retains same-parent early return, detach-before-attach/storage assignment, source-car engine selection, guard order, exact model fit, reciprocal ID writes, ordered bindings, fluid reference transfer, copied detach tune, EngineAdjustments and rank projection. Live failures retain legacy partial writes. Private failures return only exception type and exact message; the source profile remains unchanged.

The scoped adapter copies cars, engines, tunes, fluids and touched descendant parts by source reference on demand. Shared tune/fluid aliases remain shared in the private candidate; transfer setters assign already-owned references. Null bindings, tune and fluids remain null. The raw engine snapshot contains identity/model/name/storage/parent fields, ordered nullable bindings, tune and fluid values. Descendant parts/definitions and affected car inspection are optional queries with separate error fields; they cannot change Move success. An attached engine's emptied stored-slot list is not treated as a complete assembly; the affected car snapshot is the path for its fitted descendants. Changed engine snapshots follow actual write order, including a car-referenced engine that differs from the requested asset. Affected car snapshots follow source then destination order. No private candidate graph is returned on failure.
