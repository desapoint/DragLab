Target scope: `NativePartsBrowserBuild` and its real `NativeParts` presentation lifecycle. The current working checkpoint is dormant backend only: managed model/freshness/encoder assertions exist; live UI, card/action publication and native lifecycle rows below remain future required gates. It tests empty-cart current/planned preparation. Nonempty-cart behavior remains an explicitly labeled synchronous legacy case and is not a responsiveness pass. The parent owns the Editor route, Unity/native execution and Git.

All fixtures use isolated profiles/save paths. Preserve existing user state and never undo an accepted durable action to clean up. Every gated mutation is restored in `finally`; evidence distinguishes source checks, managed execution and actual native captures. The builder timing note reports its own capture/validation/setup/preparation/final-fence durations and item counts; its outer wall clock includes assertion callbacks and is descriptive only. No pass is claimed until the parent runs the focused Editor/native gates and records their results.

The initial exhaustive Shop build retains a one-item cap from capture through completion. Other parity/retry builds request a cap of 32 and assert their actual capture/preparation deltas; held mutation probes still use actual one-item steps. This avoids repeating thousands of identical whole-catalogue fences in every retry without removing entry or inspection assertions.

Unit projection has an independent, test-only full-fixture oracle. Its private reflection copier preserves exact numeric values, nested nulls, runtime member subtypes and aliases, then unchanged `InventoryUnits.Install` and `InspectionBuild.Capture` produce the comparison. All inspection inputs, curves, warnings and seven deltas are compared for owned and dealer engine members and retained-condition tires; the complete live fixture must stay unchanged. This copier is never called by gameplay, previews or saving. A JSON oracle was rejected because Unity materialized null `Tune.awd` as a default object; production preserves the original null. Failed/partial run provenance is retained under S06G1 attempt folders.
