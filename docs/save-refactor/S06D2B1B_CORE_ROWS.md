## Added matrix group

`Runtime/CartPreviewCharacterizationCoreRows.cs` contributes `RunCoreRowMatrix(Trace, subset)` to the partial Editor-only checker. `subset=null` selects all groups; `purchases` selects new sets, new units, and used part/unit loose/install groups; `new-sets` selects only the new-set group; `sales-stock` selects loose sales and sale/error/order checks plus stock; `stock` selects only the stock group. Any other value throws `ArgumentException`. Within the selected subset, groups remain independently isolated so a thrown fixture error does not stop the others. The full matrix separates ten execution groups under these five coverage areas:

- **New sets:** a real compatible `HeadIntake` offer, loose and installed quantity two. Independently calculate sequential price and fee; inspect actual Apply roots, cash, local stock, first-set installation, displaced root identity/condition, and the loose second set. Root completeness uses `EngineElements.Count` for the resolved vehicle model; `InventoryUnits.Count` is purchase quantity and returns 1 for this zero-element HeadIntake model. Installed HeadIntake ownership is expected at `Assembly`, owned by the selected car's engine assembly, with the slot binding pointing to the exact root. Both loose and installed outputs are checked with full ownership validation without calling `Ensure`.
- **New units:** enumerate every role from one actual compatible multi-member definition, with quantity two and loose output facts for each role. Select an installed definition/role only when `InventoryUnits.Positions` returns real addresses. Exercise ordered positions in reverse order if at least two exist, purchase one extra unit, and assert displaced member identity/condition plus unchanged unselected member facts.
- **Used part/unit:** use actual `AddUsedPart`/`AddUsedUnit` dealer payloads for loose purchase; also install a real fitting used part. For used unit install, bounded actual `PartsMarket.AddUsedSupply` calls seek the installed definition/role and a nonfailed member, then leave the case explicitly OPEN on a genuine shape miss. The expected installed member is copied from the actual incoming member with only cylinder and valve mapped to the explicit destination member, matching `EngineElementService.ReplacePack`; identity, role, definition, wear, fault, and other condition fields remain exact. Check displaced-member return, untouched neighbors, dealer removal, no new-market consumption for used stock, cash and exact wear/fault data.
- **Sales and asset order:** sell a real loose part and unit at the fixed wholesale time; compare `Total` to `Valuations.LoosePriceOracleForChecks` and label this shared valuation arithmetic. Preview/Apply assert that sale rows do nothing; checkout is outside this test. Cover installed/missing/wrong-kind part and unit IDs, same-ID duplicate sales, sale→move, move→sale, and sale/purchase order.
- **Sequential stock:** select an actual stocked compatible multi-member product with individual roles and change only its existing authored row’s `units` and `initialUnits` in an isolated fixture to create a globally validated controlled state: a new set consumes `count` local units, then two new units consume one remaining local and one express. Calculate each per-item fee using `ceil(basePrice * express/units * deliveryPercent/100)`, and assert Total, DeliveryFee, Apply cash and stock remainder. Record original and controlled quantities and current `market.generation`; do not create stock rows or add fields.

All paired calls continue to use the existing literal profile-clone harness and frozen oracle. Independent arithmetic/state assertions supplement parity. The cases preserve strict source graph/catalog/random assertions, including the known JSON materialization failures. Test fixtures use fixed time/policy and actual authored IDs. Deliberate stock control invokes `MechanicsOwnership.Validate` and never calls `Ensure` afterward.
