# Unity reference review

Open index.html. A recorded Tempest is preloaded; choose another configuration above its reference description. Start audio renders the recorded Unity timeline through editable browser DSP. The separate WAV player is the authoritative Unity output. Restart recorded sequence rewinds browser playback. Rendering A/B keeps the same imported timeline. Free simulation restores manual controls.

All audio is unnormalized 48 kHz stereo; native reference WAVs are 24-bit. Each trace has hardware, listener, per-wheel contact, all numeric sound frames and lossless seeded reaction/release events. Each combined A/B WAV plays Unity first, one second silence, then the browser. Reference timing is exact; browser acoustic parity is NOT claimed. No game source, save or installed build was changed.

Case files: 03-i4-turbo-hiss, 08-v8-carb, 09-v8-supercharger, 17-v8-burnout, 26-launch-hard-ignition.

Source tools and detailed schema are in tools/audio-workbench and docs/UNITY_AUDIO_REFERENCE.md.
