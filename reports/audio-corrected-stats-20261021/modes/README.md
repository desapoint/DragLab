# Unity reference review

Open index.html. A recorded Tempest is preloaded; choose another configuration above its reference description. Start audio renders the recorded Unity timeline through editable browser DSP. The separate WAV player is the authoritative Unity output. Restart recorded sequence rewinds browser playback. Rendering A/B keeps the same imported timeline. Free simulation restores manual controls. Unity inputs replays only recorded throttle and shift commands through browser physics; select Neutral / dyno or Race drive. The Sound tuning selector keeps the original Free preset by default or loads captured Unity hardware. E upshifts; Q downshifts.

The Fixed-tuning signal diagnostics panel can build a frozen comparison from matching trace/driver files. Select a pass, compare previous to selected, or download its WAV. Generated diagnostic bundles preload all passes and shorter chapter sequences. See docs/AUDIO_SIGNAL_DIAGNOSTICS.md.

Unity reference exports are unnormalized 48 kHz stereo; native reference WAVs are 24-bit. Separately labelled matched tuning auditions attenuate the louder pass for comparison. Each trace has hardware, listener, per-wheel contact, all numeric sound frames and lossless seeded reaction/release events. Each .unity-browser-AB.wav plays Unity first, one second silence, then the browser. Reference timing is exact; browser acoustic parity is NOT claimed. No game source, save or installed build was changed.

Case files: 03-i4-turbo-hiss, 08-v8-carb.

Source tools and detailed schema are in tools/audio-workbench and docs/UNITY_AUDIO_REFERENCE.md.
