# 3B — assemblies and configuration library checkpoint (2026-10-08)

Stored engines now retain complete or partial descendant trees with exact identities, individual condition/faults, oil/coolant state and engine adjustments. Detach/store/reassemble/attach can move an engine between same-platform owned chassis without creating missing parts, healing wear or refilling liquids. Chassis fuel, road hardware and ECU/gearbox/clutch remain on the vehicle. Keep/dispose/remaining previews partition actual assets; priced salvage remains 3D.

A Garage/Parts/Tuning-accessible library saves named engine + associated-control hardware, whole-car setups and tuning-only snapshots. Load previews compatible fitted/loose inventory and missing catalog purchases. Explicit Apply restores hardware/tuning atomically, can purchase sold/missing components, and retains displaced originals. Blueprints contain desired definitions and applied adjustments, never physical item identities, health or resources. Tune-only apply respects installed hardware permissions and can update incomplete chassis without making them runnable. Compatible cross-platform individual parts remain supported; engine mounts currently require the same vehicle platform.

Player schema 4 adds detached assembly storage and the saved library. Schema-3 migration commits existing identities and keeps `.legacy-v3`. Active runs/rebuild reservations, exclusive parents, compatibility, price changes, insufficient cash, stale previews and failed persistence are guarded. Reset clears the new progression assets. The shared simulation model stays v15; no duplicate engine/economy solver was introduced.

Current domain gates: 179 assembly/configuration/ownership/inventory checks, 333 expanded recovery/ownership/inventory checks (296 focused recovery + 37 existing ownership/inventory) and 1,096 service/fluid checks. These overlap some prior regression checks and are not summed into a unique-check claim. Scene wiring and Windows build pass. Native Windows workflows cover saved-config/missing-purchase/partial assembly/reassembly/transfer/race/reload (13 checks), collection/new-car purchases/duplicate race (12), Parts/service/individual replacements/rebuild reservation (41) and reset/preserved preferences (22).
