## Changes

- Add collapsible Induction/exhaust, Transmission/drivetrain, Tires/wheels, Weight/balance, Cooling/fluids, Components/saved tuning and Performance/warnings groups using the accepted Engine rows, shared palette/surfaces, info dialogs and range bars. Other groups start closed and build contents only on first expansion. Visibility and disclosure states remain local UI state; no editable tuning controls or Tab traversal are introduced.
- Display actual installed configurations, applied permissions and retained resources/condition. Include settled boost and induction response, converter versus friction-clutch behavior, sequential gearbox timing, CVT endpoints, per-gear theoretical speeds/shift landing RPM, AWD topology and applicable coupling fields. Convert pressure, speed and torque through selected units; external tire radius/diameter use inches. Explain reference life/consumption values and theoretical speeds through info controls rather than claiming remaining mileage or achievable top speed.
- Separate translating/rotating load, flywheel/engine inertia, axle loads and actual fuel mass. Cooling reports condition-adjusted heat transfer/rejection, retained fluid quantities/quality/temperatures and leak/consumption totals. Component details retain exact owned identities, installed names, fixed/adjustable hardware, applicable category ratings, individual cylinder/valve faults and tire-corner condition. Non-wearing trim has no fabricated condition/strength rating; absent hardware stays absent.
- Nest gearing, continuous acoustic exhaust sections, saved tuning, installed components and individual elements/corners. Shared definition IDs and current/proposed union handling permit reuse without making a new theme or duplicating simulation. Comparison-page integration is still separately gated.
- Opening Performance requests a cached background automatic quarter-mile estimate through the existing CarInspection/CarSimulation authority. Capture and resource-backed preparation occur on the main thread; bounded domain simulation runs on a copied build in a worker. The standard estimate uses automatic driving, traction assist off and full wear, independently of player assists; info identifies this assumption. It updates only performance/warning rows. Cache entries use profile revision/owned identity, old completed entries are pruned, detached views cannot overwrite another panel, and disclosure toggles reuse the completed result. Pending/error/incomplete estimates are explicit; incomplete passes do not fabricate elapsed times. Warning info includes the authoritative explanation and suggestion.
