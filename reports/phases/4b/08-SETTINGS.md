## Delivered

- Five populated categories: Difficulty / Driving, Sound, Units, Controls and General. Existing options keep their authoritative meanings: driving presets, shifting/launch, opponent difficulty, simulation presets, wear, fuel, fluid depletion/aging, condition effects, fluid service, heat management, race-start temperature, warm-up, throttle/clutch/stall/traction/rev-match/shutdown assists and clutch release time. Reduced wear/fuel/fluid/condition rates remain 25%. Race-start temperature stays remembered and disabled while continuous heat management is off.
- Shared master/opponent volume sliders with numeric entry; speed, pressure and torque choices. Controls lists actual fixed bindings and pedal help; this does not implement remapping. General retains the existing progression-reset command and its independent confirmation.
- One draft across tabs. Edits do not publish audio, units, difficulty or profile changes and do not save. Apply opens an actual-change confirmation; its Apply validates and persists the intended change. X/Cancel/Escape closes only the dialog. Page Cancel discards and returns to the menu used to open Settings. Revert stays and reloads applied values. Dirty navigation offers Apply / Discard / Stay.
- F8 preserves the draft/category; native text focus, pointer gestures and dialogs block comparison. Definitive legacy preference changes merge into unrelated draft fields; conflicting edits block Apply until Revert. Confirmation is regenerated if the pending changes change. Legacy navigation cannot silently discard a native dirty draft. Applying preferences does not recreate owned cars/parts or replace a race's captured simulation rules.
- Settings persistence uses a durable undo journal around the existing profile, profile backup, audio and unit files. Publish caches only after the commit marker. Failed writes retain the old live state; incomplete writes restore exact prior files/absence before scene load, including bench launches. Completed commits survive journal-cleanup interruption. Reset preserves applied preferences and never publishes unsaved Settings drafts.
- Slanted brushed tabs (straight first left edge), grey/red multitone choices, rounded toggle switches, red slider fills, readable dark numeric fields and themed scrollbars. Framed content has upper-left/lower-right red highlights; Apply/Cancel remain outside scrolling content. No repeated category headings/subtitles/descriptions.
- Existing header layout/nav styling retained. Only the requested decorative top bars and small Settings glint are removed. Top/bottom red trim fades into transparency; bottom-right terminal mirrors the left. Denser glow geometry and static low-amplitude point-sampled dithering reduce 8-bit banding. Dither is generated once, cached and decorative; no gameplay RNG or frame-by-frame noise.
- Hover/focus shine runs once and completes even after pointer leave. Focus gained by clicking an already hovered button does not restart it. Selection/pressed changes retain the sweep clock. Settings/slanted controls sweep in their own parallelogram basis.
